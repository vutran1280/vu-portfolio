01 / Challenge

Complex tabulation from GIS datasets

Preparing FIS tables manually involved identifying the correct FEMA data sources, joining geographic and hydraulic records, transferring information into standardized table structures, and reconciling outputs with database records. The previous workflow required more than 20 hours for comparable projects.

02 / Solution

Automate GIS processing and report generation

I developed a master application that detects available inputs and coordinates table-specific generators. Its registry lists 32 possible FIS table types, with 27 marked as implemented in the source. Actual applicable tables depend on the data available for a project.

03 / GIS engineering

Spatial relationships drive the reporting

The code handles relationships between features such as community polygons, FIRM panels, subbasins, cross sections, and hydraulic elevation records. These relationships determine which values belong in the corresponding FIS tables.

Example sources include S_Pol_Ar, S_FIRM_Pan, S_Subbasins, S_XS, and L_XS_Elev. This is why the project showcases geospatial data engineering rather than only Excel formatting.

04 / Results

Table generation in minutes

The generator has been used on more than 10 FIS projects, with the user reporting consistently produced tables and an average generation time of three to five minutes.

Compared with a conservative baseline of 20 hours (1,200 minutes), five minutes implies a 99.58% estimated reduction in generation time, or at least 19 hours and 55 minutes saved per comparable project. Formatting, engineering checks, reconciliation, and final approval may require additional time.

05 / Quality control

A repeatable reference for FIS/database consistency

Because the outputs are derived from project database records, reviewers can compare the generated tables with existing FIS documentation to find potential discrepancies. The master script also logs missing inputs, skipped tables, and processing errors.

Scope of the claim: The supplied master script coordinates template-based exports and workbook consolidation. It does not, by itself, demonstrate a fully automated comparison against a published FIS report or guarantee regulatory compliance.
