1D Floodplain Interpolation

A Python-based application that converts cross-section water-surface elevations and terrain data into interpolated WSEL rasters, flood-depth grids, and inundation polygons.

The core idea

Generate floodplain products without the original HEC-RAS model file.

When cross-section geometry and water-surface elevations are available, this application provides a GIS-based workflow for creating floodplain products without requiring the source HEC-RAS model file itself.

It does not estimate water-surface elevations from terrain alone—the cross-section elevations must already be available.

01 / Challenge

Manual interpolation takes hours

Producing water-surface and flood-depth rasters through repeated ArcGIS Pro operations previously took about two hours or more for a representative stream. The process involved preparing cross sections, interpolating surface elevations, comparing against terrain, and delineating floodplain boundaries.

02 / Algorithm

Interpolate between adjacent cross sections

I built a custom interpolation routine that groups cross sections by stream, sorts them by station, constructs regions between neighboring sections, and calculates a water-surface elevation for each raster cell based on its relative distance to the bounding cross-section lines.

t = dup / (dup + ddown)
WSEL = WSELup + t × (WSELdown − WSELup)
Flood depth = WSEL − DEM

The algorithm handles distance weighting within each interpolation region; it does not substitute for a hydraulic simulation.

04 / Results

Five minutes for a 10-mile stream

For a reported 10-mile stream, the application completed processing in approximately five minutes. A 25-mile stream completed in under fifteen minutes.

Compared against the previously reported manual workflow of two hours or more, a five-minute run would represent at least 95.8% less processing time for equivalent inputs and deliverables. This figure is provisional because a controlled same-stream benchmark has not yet been documented.

05 / Quality assurance

Compare outputs with RAS Mapper

The generated boundaries are compared with HEC-RAS RAS Mapper outputs to assess spatial consistency and identify areas requiring review. This is a validation approach, not evidence of numerical equivalence; quantitative agreement has not yet been established.

The application also exports intermediate interpolation geometry for QC. Its practical use case is when cross-section WSEL attributes exist but the original hydraulic model files are not available.
